Give every gesture a chance to be understood.

An open-source sign-recognition project that turns MediaPipe hand and body landmarks into sign predictions with a PyTorch LSTM, designed for the WLASL100 vocabulary.

Get started Explore the code

Model status: waiting for training data. The webcam prediction app is ready to run after training. WLASL videos and a trained checkpoint are not included, so this hosted page does not claim to make live sign predictions. Follow the dataset access terms before downloading or using WLASL.

How it works

01 / TRACK

Capture landmarks

MediaPipe Holistic extracts body pose and both hand positions from each frame.

02 / LEARN

Understand sequences

A PyTorch LSTM learns motion across a sequence of landmarks using WLASL splits.

03 / PREDICT

Run from a webcam

The local demo displays a predicted sign and confidence once a trained model is available.

Run it locally

Install the dependencies, obtain the dataset under its terms, then train and start the webcam app:

pip install -r requirements.txt
python -m sign_language.train --annotations data/WLASL_v0.3.json --videos data/videos --output models/wlasl100.pt
python -m sign_language.webcam --model models/wlasl100.pt

See the repository README for Python setup, dataset instructions, and command options.
